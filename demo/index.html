A desktop app that reads a codebase and shows what it does as stories: what happens when a screen opens, a button is pressed, a request arrives or a job runs. Each story is a sequence diagram, and every step leads down to the lines that wrote it.

Below is the app's real interface in the browser, on models it read earlier. The desktop app reads a project folder itself, with language servers, and never runs the project's code.
